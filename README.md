# Pilares-da-Mecat-nica-PT-BR-Pillars-of-Mechatronics-EN
Página educativa sobre os 4 pilares da mecatrônica (Mecânica, Eletrônica, Computação, Controle). Traz um diagrama de blocos interativo mostrando o ciclo mede→processa→decide→atua, e um glossário visual com 8 componentes (motor de passo, encoder, PLC, sensor, atuador pneumático, driver, microcontrolador, IMU) em cartões que viram ao clicar.
